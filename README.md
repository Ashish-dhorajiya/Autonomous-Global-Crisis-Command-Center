# 🌍 AegisGlobal AI - 3D Autonomous Crisis Command Deck
> **3D સ્વાયત્ત વૈશ્વિક કટોકટી અને સપ્લાય-ચેન કમાન્ડ સેન્ટર**  
> *A World-Class Multi-Agent Geopolitical & Maritime Crisis Simulation Engine*

---

## 🚀 પ્રોજેક્ટ પરિચય (Project Overview)
જ્યારે સુએઝ નહેર બ્લોક થાય છે, અરબી સમુદ્રમાં વાવાઝોડું આવે છે કે લાલ સમુદ્રમાં મિસાઇલ હુમલા થાય છે, ત્યારે વૈશ્વિક શિપિંગ કંપનીઓ (Apple, Tesla, Amazon) ને અબજો ડોલરનું નુકસાન થાય છે. 

**AegisGlobal AI** એ એક અદ્યતન 3D કમાન્ડ ડેક છે જેમાં **૪ સ્વાયત્ત AI એજન્ટ્સ (4 Autonomous Swarm Agents)** રિયલ-ટાઇમમાં વૈશ્વિક કટોકટી શોધીને, માત્ર ૫ સેકન્ડમાં આખી દુનિયાના જહાજોના સમુદ્રી માર્ગો આપોઆપ બદલી નાખે છે (3D Re-routing) અને અબજો રૂપિયાનો માલ બચાવે છે!

## 🛠️ પ્રોજેક્ટ આર્કિટેક્ચર અને ફાઇલ્સ (Project Structure)

| ફાઇલ / ફોલ્ડર | શું કામ કરે છે? |
| :--- | :--- |
| **`app.py`** | FastAPI બેકએન્ડ સર્વર, જે 3D ઇન્ટરફેસ સર્વ કરે છે અને 4 એજન્ટ્સ વચ્ચે કમ્યુનિકેશન કરાવે છે. |
| **`agents.py`** | ચારેય સ્વાયત્ત AI એજન્ટ્સનું મુખ્ય મગજ: <br>• **Agent 1 (SENTINEL-1):** હવામાન અને ભૂ-રાજકીય જોખમ સ્કેનર<br>• **Agent 2 (NAVEX-4):** 3D સમુદ્રી માર્ગ ઓપ્ટિમાઇઝર<br>• **Agent 3 (QUANT-X):** નાણાકીય નુકસાન અને કાર્બન ઓડિટર<br>• **Agent 4 (DIPLOMAT-PRIME):** એક્ઝિક્યુટિવ એક્શન ડાયરેક્ટિવ અને ઇન્શ્યોરન્સ ફાઇલિંગ |
| **`simulation_data.py`** | મુંબઈ (JNPT), શાંઘાઈ, સિંગાપોર, રોટરડેમ જેવા મુખ્ય બંદરો અને સુએઝ કેનાલ, તાઇવાન સ્ટ્રેટ જેવા ચોકપોઇન્ટ્સનો અક્ષાંશ-રેખાંશ ડેટા. |
| **`static/index.html`** | GPU-એક્સિલરેટેડ **Three.js & Globe.gl** દ્વારા સંચાલિત 3D ગ્લોબ, નિયોન સાયબરપંક HUD અને ગુજરાતી/અંગ્રેજી બહુભાષીય ડેશબોર્ડ. |
| **`run.bat`** | વિન્ડોઝ માટે **વન-ક્લિક લોન્ચર** (માત્ર ડબલ-ક્લિક કરવાથી પ્રોજેક્ટ બ્રાઉઝરમાં ચાલુ થઈ જાય છે). |

## 🎮 પ્રોજેક્ટ કેવી રીતે ચાલુ કરવો? (How to Run)

### રીત ૧: સૌથી સરળ (Double Click)
1. તમારા Desktop પર જાવ.
2. **`AegisGlobal`** ફોલ્ડર ખોલો.
3. **`run.bat`** ફાઇલ પર ડબલ-ક્લિક કરો! 
4. આપમેળે તમારા બ્રાઉઝરમાં **http://127.0.0.1:8000** ખુલી જશે.

### રીત ૨: VS Code દ્વારા
1. VS Code ખોલો.
2. `File` ➔ `Open Folder` ➔ `Desktop/AegisGlobal` પસંદ કરો.
3. ટર્મિનલમાં લખો:
```bash
python app.py
```
4. બ્રાઉઝરમાં ખોલો: `http://127.0.0.1:8000`

## 🌟 મુખ્ય વિશેષતાઓ (Key Features)
* **Interactive 3D Earth Globe:** માઉસથી 360 ડિગ્રી પૃથ્વી ફેરવી શકાય છે, ઝૂમ કરી શકાય છે.
* **3D Glowing Maritime Arcs:** સમુદ્રી માર્ગો પર જહાજો ફરતા દેખાય છે.
* **Danger Zone Red Holographic Rings:** કટોકટી વાળા વિસ્તાર પર લાલ રિંગ્સ પલ્સ થાય છે.
* **Emerald Green Bypass Corridors:** એજન્ટ 2 દ્વારા જનરેટ થયેલા સુરક્ષિત નવા રસ્તા લીલા રંગથી દોરાય છે.
* **Bilingual UI:** એક જ ક્લિકમાં ગુજરાતી અથવા અંગ્રેજી ભાષા પસંદ કરી શકાય છે!
